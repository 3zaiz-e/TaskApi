# Task API (CRUD Web API)

A simple, lightweight CRUD API built with **ASP.NET Core Minimal APIs** and an in-memory data store, complete with a clean interactive frontend interface.

## Features
- **Create**: Add new tasks with input validation.
- **Read**: View all tasks or retrieve a single task by ID.
- **Update**: Modify existing tasks or change their completion status.
- **Delete**: Remove tasks.
- **Swagger UI**: Interactive API documentation available at `/swagger`.
- **Frontend UI**: Built-in HTML dashboard for quick testing.

---

## Prerequisites
- .NET 8.0 SDK (or compatible .NET runtime) installed on your machine.
